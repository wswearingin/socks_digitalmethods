classpatch.models.audioset_vocab module¶

AudioSet ontology labels (527 classes).

Shared by any model whose label space is AudioSet. Kept as a module-level constant so other parts of the pipeline (e.g. label groups used by routing rules) can import the vocabulary without instantiating a model.

classpatch.models.sslam module¶

SSLAM wrapper for the AudioSet-2M finetuned checkpoint.

Wraps the preprocessing and inference path documented on the SSLAM model card behind the classpatch.base.AudioClassifier contract so the executor can treat SSLAM as one node in a routing graph alongside other models.

Bases: AudioClassifier

SSLAM AudioSet-2M classifier (527 classes).

Internally chunks input audio into fixed window_seconds-long windows (default 10 s) and runs the model on each, returning per-chunk :class:`Prediction`s with absolute timestamps.

Construction is cheap; weights are pulled on the first call to load() (or implicitly by classify()).

classify(segment: Segment, score_floor: float = 0.0, top_k: int | None = None) → list[Prediction][source]¶

Classify segment and return per-sub-window predictions.

Implementations:

  • Resample segment to target_sample_rate if necessary.

  • Split it into the model’s native window size internally.

  • Emit one or more Prediction`s per sub-window, with absolute time ranges anchored in ``segment.source_path`.

  • Apply score_floor and top_k per sub-window before returning. Results are sorted by score descending.

Both filters default to permissive values so the executor can apply its own routing thresholds globally.

classpatch.models.stub module¶

Stub classifier for end-to-end pipeline tests.

StubClassifier implements the AudioClassifier contract but performs no real inference: it returns a fixed list of (label, score) pairs for every input segment. Useful for exercising routing and executor logic without depending on a real model.

class classpatch.models.stub.StubClassifier(name: str, fixed_predictions: Iterable[tuple[str, float]], target_sample_rate: int = 16000)[source]¶

Bases: AudioClassifier

A no-op classifier that returns canned predictions.

Parameters:

  • name (str) – Identifier used in routing tables (e.g. "stub_birdnet").

  • fixed_predictions – (label, score) pairs returned on every call to classify(). Each gets the input segment’s absolute time_range.

  • target_sample_rate (int) – Native sample rate (defaults to 16 kHz). The pipeline resamples slices to this rate before handing them over.
